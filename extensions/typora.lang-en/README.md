# English Spelling Dictionaries

Checks English (US and UK) spelling when the system has no spellchecker or no English dictionary, as on Linux.

Pick **en-US** or **en-GB** in Settings ▸ Editor ▸ Spelling Language. The Hunspell dictionaries come from [typora/dict.typora.io](https://github.com/typora/dict.typora.io); each folder under `dictionaries/` has its LICENSE.
