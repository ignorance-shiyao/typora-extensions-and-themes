# 日本語 Language Pack

Shows Typora in Japanese.

Choose **日本語** in Settings ▸ General ▸ Display Language.

Translations come from the community translators of [typora/Typora-i18n](https://github.com/typora/Typora-i18n); strings new in Typora 2 were added by Typora and await review by native speakers — corrections are welcome.
