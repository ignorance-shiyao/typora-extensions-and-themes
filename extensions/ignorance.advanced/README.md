# Ignorance Advanced

给 Typora 增加演示面板、行内徽章与彩色高亮、图表索引侧栏、中英文空格格式化，以及汇报模板。

## 内容

| 功能 | 说明 |
|---|---|
| 演示面板 | 在详情栏把当前文档按 `---` 或标题分页；支持版式注释、脚注、图标短码、KaTeX 公式；可全屏放映 |
| 演示里的图表 | 内置绘制，不依赖图表库。` ```chart ` 代码块使用 Typora 官方图表扩展的格式（`type`、`title`、`series` 加数据行），支持 bar、line、pie，其他类型显示源码并给出原因 |
| 演示里的 Mermaid 图 | 内置绘制。支持流程图（`graph` / `flowchart`：节点、箭头、连线文字、回路、嵌套 `subgraph`）、序列图（参与者、消息、注释、激活、`autonumber`、`loop` / `alt` / `opt` / `par` 块）、饼图、甘特图（分组、`done` / `active` / `crit` / `milestone`、`after`、天周小时时长，仅 `YYYY-MM-DD`），其他 Mermaid 图显示为源码并给出原因 |
| 行内徽章与高亮 | `((green:构建 \| 通过))`、`((green:完成))`（单值；颜色 blue、green、orange、red、purple、amber、gray）、`((spoiler:...))`、`((ruby:...))`、`((crumb:...))`，以及 🔴🟠🟢🔵🟣 彩色高亮 |
| 图表与图片侧栏 | 按标题列出文档里的代码块、表格、公式与图片 |
| 格式化 | 命令面板「Format Document: 整理 Markdown」整理标题、列表、空白、中文标点、中英文空格与斜体标记，规则见下文；「中英文之间加空格」可单独执行 |
| 列表大纲 | 详情栏「列表大纲」按层级显示列表；命令：上移、下移、提升、降低层级（快捷键 ⌘⇧F7 至 ⌘⇧F10）、查看分支、查看前几层、选中文本转列表、选中列表转标题 |
| 表格 | 光标在表格里时，右键菜单和行内面板提供按列升序、降序排序、重新计算公式、追加合计行、转置；命令「将选中的 CSV 转为表格」 |
| 自然语言日期 | 命令「插入自然语言日期」和「将选中文字转换为日期」；日期格式和每周起始日在设置里选择 |
| 片段与模板 | 徽章片段；汇报模板 |

设置里的「在演示里显示双猫」控制封面右下角和最后一页的吉祥物，默认关闭。

编辑器里的 ` ```mermaid ` 由 Typora 自带渲染，` ```chart ` 由官方图表扩展渲染，格式相同。

## 权限

只声明 `document: write`。演示面板和侧栏读取当前文档，整理命令由 Typora 应用格式化结果。

## 第三方库

以下库取自各自的发布包，除 Lucide 数据文件加了 `export default` 前缀外未做修改，许可文本放在同一文件夹。

| 库 | 版本 | 许可 | 用途 | 文件 |
|---|---|---|---|---|
| KaTeX | 0.16.11 | MIT | 演示里的数学公式 | `vendor/katex/` |
| Lucide（`@iconify-json/lucide`） | 1.2.136 | ISC | 演示里的图标短码 | `vendor/lucide-icons.js`（发布包的 `icons.json`，前面加了 `export default` 以便按模块加载，数据与发布包逐项一致） |

两者是上游发布的压缩版本；本扩展自己的代码都是可读源码。

注音请用 `((ruby:道 | dào))`。VLOOK 的 `_^dào^_` 在 Typora 里按 CommonMark 解析，中间的下划线会被配成斜体，扩展无法改变这一解析，因此不支持。

## Markdown 规则整理

在命令面板手动执行「Format Document: 整理 Markdown」。扩展设置可单独关闭各项规则，并选择列表缩进宽度。整理涵盖标题、列表、空白、中文标点、中英文空格与斜体标记。按句判断中文标点，保留英文标点及数字分隔符。`#标题` 会按标题处理。围栏代码、数学块、表格、Front Matter、行内代码和链接地址保留原样。可用「中英文之间加空格」单独处理间距。

按 [Typora Worker API](https://docs.typora.io/extensions/worker-api#formatters) 的约定，整篇替换记为一次撤销。可用仓库 `samples/功能总览.md` 中的「Markdown 规则整理」示例验收。
