# Galego Language Pack

Shows Typora in Galician, and checks Galician spelling when the system spellchecker has no Galician dictionary.

Choose **Galego** in Settings ▸ General ▸ Display Language. Pick **gl** in Settings ▸ Editor ▸ Spelling Language if your system has no Galician spelling dictionary.

Translations come from the community translators of [typora/Typora-i18n](https://github.com/typora/Typora-i18n); strings new in Typora 2 were added by Typora and await review by native speakers — corrections are welcome. The Hunspell dictionaries come from [typora/dict.typora.io](https://github.com/typora/dict.typora.io); each folder under `dictionaries/` has its LICENSE.
