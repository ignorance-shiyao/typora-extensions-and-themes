# 汉字的排版

文字是有温度的。一页好的中文，正文要**疏朗**，强调要*含蓄*，`行内代码`和[链接](https://typora.io)都不该喧宾夺主，只有真正要紧的地方才用==高亮==标出来。

> 排版的目的不是让人注意到排版，而是让人读得舒服。

## 几条小建议

- 选一款适合正文的字体
- 留出足够的行距
  - 行高宜在字号的一点六倍以上

1. 通读一遍
2. 打印校样

### 字号与行距

| 用途 | 字号  | 行距 |
| ---- | ----- | ---- |
| 正文 | 16 px | 1.8  |
| 注释 | 13 px | 1.5  |

```js
function measure(text, width) {
  const words = text.split(" ");
  return words.length / width;
}
```
