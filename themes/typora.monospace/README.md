# Monospace

A coder-friendly theme that shows the rendered document close to its source: `#` headings, `*` bullets and `[x]` tasks stay on the page, in Inconsolata. It keeps rendered images, tables and code colours.

Rebuilt for Typora 2 from Typora 1's Monospace and Monospace Dark. It is now one theme that follows your appearance.
