# Han

*Han* is a theme designed for Chinese articles, based on [typo.css](https://github.com/sofish/typo.css). It is rebuilt for Typora 2 from the Typora 1 theme of the same name.

*Han* 是为中文设计的主题，基于 [typo.css](https://github.com/sofish/typo.css)，由 Typora 1 的同名主题为 Typora 2 重写。

It uses the fonts on your computer: PingFang SC on macOS and Microsoft YaHei on Windows.
